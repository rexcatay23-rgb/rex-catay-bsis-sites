Academic Framework

BSIS Core Domains & Subjects

The Bachelor of Science in Information Systems bridges business operations and information technology. Explore the foundational pillars covered in our curated site library.

Information & Data Management

Database systems, SQL, relational modeling, data warehousing, data governance, and big data architecture fundamentals.

Key Books: Database Processing, Data Strategy

Systems Analysis & Architecture

SDLC methodologies, requirement engineering, UML diagrams, Agile frameworks, and Enterprise Architecture design.

Key Books: Kendall SAD, Enterprise Architecture

IT Project Management

Planning, scope management, risk assessment, resource allocation, and IT service management (ITIL) standards.

Key Books: IT Project Management (Kathy Schwalbe)

Web & Mobile Application Dev

Full-stack development, API integration, front-end UX/UI design, mobile applications, and cloud computing principles.

Focus: Modern Web Architectures & Stack

IT Infrastructure & Security

Networking fundamentals, cybersecurity, information assurance, enterprise compliance, and cloud deployment models.

Focus: Infrastructure Resilience & Security

Business Intelligence & Analytics

Data analytics, decision support systems (DSS), business process re-engineering, and AI/ML applications in IS.

Key Books: Data Strategy, Fundamentals of IS

How to Publish "Rex Catay Site" Live for Free

You can publish this single-file BSIS web portal live on the internet using free cloud hosting platforms like GitHub Pages, Vercel, or Netlify.

Option 1: GitHub Pages (Recommended)

  1. Create a free account at GitHub.com.
  2. Create a new repository named rex-catay-bsis-site.
  3. Upload this file and rename it to index.html.
  4. Go to Settings > Pages in your repository.
  5. Under Branch, select main and click Save.
  6. Your site will be live at: https://username.github.io/rex-catay-bsis-site/

Option 2: Netlify Drop (Instant)

  1. Save this file as index.html inside a folder.
  2. Go to app.netlify.com/drop.
  3. Drag and drop the folder into the deployment box.
  4. Your site is instantly published with an SSL/HTTPS web URL!
